# Cross-Platform Development

A collection of Flutter projects. Each folder is a standalone Flutter app.

| Folder | Description |
| --- | --- |
| [`dice_roller/`](dice_roller/) | Dice roller app with a gradient background |
| [`gradient_proj/`](gradient_proj/) | Gradient background starter project |

## Running a project

```bash
cd <project_folder>
flutter pub get
flutter run
```
